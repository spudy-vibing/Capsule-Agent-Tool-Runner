# Capsule v0.2.0-beta.1 — Eval Harness & Distribution

## Context

Alpha.3 (Pack System) is complete with 655+ tests, anti-hallucination validation, and two bundled packs. The next milestone is **beta.1**: an evaluation framework to test packs systematically, plus PyPI packaging for distribution. Test case YAML files already exist in `packs/*/evals/test_cases.yaml` — the harness needs to load, run, and score them.

---

## Step 1: Eval Schema Models

**Create** `src/capsule/pack/eval.py`

Pydantic models to parse the existing test case YAML format:

- `EvalExpected` — expected outcomes (decision, reason_contains, output_contains, output_not_contains, output_is_json, task_completed, input_error, error_contains)
- `SetupFile` — file to create before test (path, content, size_kb)
- `InjectToolCall` — tool call for deterministic policy testing (tool, args)
- `EvalTestCase` — single test case (name, description, input, inject_tool_call, setup_files, expected)
- `EvalSuite` — full suite from YAML (version, pack, test_cases, scoring weights)

All models: `frozen=True`, `extra="forbid"`, following `schema.py` conventions.

---

## Step 2: Eval Runner & Scorer

**Same file** `src/capsule/pack/eval.py`

Result dataclasses:
- `CheckResult` — single assertion (check_type, passed, expected, actual, message)
- `TestCaseResult` — one test case (name, passed, category, checks, duration_seconds, error)
- `EvalRunResult` — full suite (pack_name, total, passed, failed, skipped, results, score, score_breakdown, duration_seconds)

`EvalHarness` class:
- `load_suite(pack_name)` — load `evals/test_cases.yaml` from pack directory
- `run_suite(suite, category="all", planner=None)` — run all test cases
- `_run_deterministic_case(case, pack_loader)` — policy injection tests (no LLM needed):
  1. Load pack policy → create `PolicyEngine`
  2. If `inject_tool_call`: evaluate policy directly, check decision/reason
  3. If `expected.input_error`: validate inputs, catch error
- `_run_planner_case(case, pack_loader, planner)` — full agent loop tests (requires Ollama):
  1. Render prompt template with inputs
  2. Set up temp files from `setup_files`
  3. Run `AgentLoop` with planner + policy
  4. Check `AgentResult` against expected (task_completed, output_contains, etc.)
- `_check_expected(expected, actual)` → `list[CheckResult]`
- `score(result, weights)` → weighted average of metric ratios in [0,1]

**Auto-classification:** test case has `inject_tool_call` → deterministic (CI-safe); otherwise → planner (local-only, requires Ollama).

## Step 3: Eval Error Types

**Modify** `src/capsule/errors.py`

Add error codes 8001-8004 following existing `PackError` pattern:
- `EvalSuiteNotFoundError` (8001) — no `evals/test_cases.yaml` in pack
- `EvalInvalidSuiteError` (8002) — YAML fails Pydantic validation
- `EvalPlannerRequiredError` (8004) — planner tests requested but no planner available

## Step 4: Eval DB Storage

**Modify** `src/capsule/store/db.py`

New table:
```sql
CREATE TABLE IF NOT EXISTS eval_runs (
    eval_id TEXT PRIMARY KEY,
    pack_name TEXT NOT NULL,
    category TEXT NOT NULL,
    total_cases INTEGER NOT NULL,
    passed_cases INTEGER NOT NULL,
    failed_cases INTEGER NOT NULL,
    skipped_cases INTEGER NOT NULL,
    score REAL,
    score_breakdown_json TEXT,
    results_json TEXT NOT NULL,
    duration_seconds REAL NOT NULL,
    created_at TEXT NOT NULL
);
```

New methods on `CapsuleDB`:
- `record_eval_run(...)` → eval_id
- `get_eval_run(eval_id)` → dict | None
- `list_eval_runs(pack_name=None, limit=100)` → list[dict]

## Step 5: Eval CLI Commands

**Modify** `src/capsule/cli.py`

Add `eval_app = typer.Typer()` subcommand group (same pattern as `pack_app` at line ~1464):

| Command | Description |
|---------|-------------|
| `capsule eval run <pack_name>` | Run eval suite (--category deterministic\|planner\|all, --model, --json, --db) |
| `capsule eval score <eval_id>` | Display score breakdown for a previous eval run (--json, --db) |
| `capsule eval list` | List previous eval runs (--pack, --limit, --json, --db) |
